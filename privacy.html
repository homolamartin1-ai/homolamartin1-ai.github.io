Privacy Policy

Martin Reels (Vibetesting) · Last updated 5 November 2026

Martin Reels is a private automation tool operated by Martin Homola. It publishes short educational videos that he creates to his own channels on YouTube, Instagram and Facebook. It is not a public service and has no users other than its owner.

YouTube API Services

Martin Reels uses the YouTube API Services to upload videos to the owner's YouTube channel. By using Martin Reels you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Information the tool accesses, uses and stores

With the owner's explicit authorisation (Google OAuth 2.0), the tool uses these scopes for the owner's own YouTube channel only:

  • youtube.upload: to upload the owner's videos, with their title, description and tags, to the owner's channel (YouTube Data API videos.insert);
  • youtube.readonly: to confirm which channel is connected and read its basic statistics (channels.list, videos.list).

Stored: the OAuth refresh token (in the owner's encrypted secrets store) and the ID and link of each uploaded video (in the tool's private log, so the owner can find his own videos). Channel and video statistics are shown to the owner and are not stored for more than 30 days.

The tool also publishes to the owner's own Facebook Page and Instagram professional account through Meta's Graph API.

Sharing

No YouTube or Google user data is sold or shared with third parties. The only place a result is sent is the owner's own private Telegram chat, where the tool sends him the link to the video it uploaded. The tool does not use cookies and does not collect any data about visitors to this website or members of the public.

Google API Services User Data Policy

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page: security.google.com/settings/security/permissions. For Meta, use Facebook's Business integrations settings.

When access is revoked, or on request through the contact below, the stored tokens and all stored API data are deleted within 7 days. Videos already uploaded stay on the owner's YouTube channel and can be deleted there in YouTube Studio.
